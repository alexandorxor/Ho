# HO — CHRISTMAS01

Репозиторий для исходников и продолжения работы. Создан по прямому указанию владельца 2026-11-06. Цель владельца: получить JPG сцены, прошедшей весь согласованный цикл; промежуточный концепт не выдавать за финал.

## Текущее состояние

**BLOCKED: актуальные исходники последнего этапа отсутствуют в доступной рабочей папке.** Доступный HO_Studio содержит более ранние версии вплоть до v12. Его резервная копия не доказывает актуальность и не заменяет v15b/v16.

См. [CONTINUATION.md](CONTINUATION.md) для решений, границ подтверждения и следующего шага. `backups/` предназначен для байтовых копий исходников с SHA-256 и инструкцией восстановления. Наличие этого README само по себе не означает, что загрузка резервной копии завершена: проверять backup manifest и журнал загрузки.

## Правило продолжения

Каждый запуск начинает с фактически доступных файлов, AGENTS.md, версии стандарта, профилей и журналов. Не предполагать живых исполнителей из прежней сессии. Не подменять QA автором, не переносить PASS между хэшами. Обычные разрешённые FIX доводить до независимой повторной проверки; неизвестный статус не считать сбоем и не запускать дубль.

Новые исходники, зависимости, task cards, журналы и результаты сохранять в этом репозитории версионно. Указывать commit SHA и SHA-256 мастер-файла в передаче. Не фиксировать ключи доступа и персональные данные среды.
